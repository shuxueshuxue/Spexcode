# review

The **review-track** prose presets live here: leaf plugins whose body is a remark template. Nothing reads
the surface — no loader gathers it, no route lists it, no composer offers a `/<name>` menu — so the leaves
are declared nodes that reach no runtime. A preset is prose only; it never adds a write mechanism.

This node is a **shelf, not a surface**. Its routing and relocation invariant is owned once by
[[.plugins]]'s shelf invariant. First resident: [[refuse]], a structured objection to a scenario's verdict —
a subject with no reading behind it now.
