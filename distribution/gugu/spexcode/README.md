# SpexCode for gugu

Spec tree, drift and diagrams.

What people read about this App in gugu's market is in `store/`: `about*.md`, `screenshots/` and `whats-new.md` (this version's changes). `manifest.json` is generated by `scripts/distribution.mjs`; what agents read is its `contributes.instructions`, the tools in `tools.js` and the skills. This README and `CHANGELOG.md` are for the repository and are never shown in gugu. Source: [shuxueshuxue/Spexcode](https://github.com/shuxueshuxue/Spexcode).
