A spec node that bears on what you are reporting is named as a title-only wiki link: `[[node-id]]` — what
you changed, what you read as contract, what your change works against. The backticks there mark a
PLACEHOLDER; a real name goes without them, because a backticked one is read as sample text and stays plain
everywhere. Anywhere you write it counts: a
declaration note, a message, an issue or remark body, your own visible output — every surface a human reads
you on renders it as a link into that node.
